# 🌤️ SkyMessage — Полнофункциональный веб-мессенджер

## 📋 Описание

**SkyMessage** — это современный веб-мессенджер с богатым функционалом, объединяющий в себе чат, видеоплатформу, почту, фитнес-трекер и карты. Всё работает прямо в браузере без необходимости установки сервера!

> 🚀 **Особенность**: Полностью клиентское приложение на HTML/CSS/JS с использованием localStorage для хранения данных.

---

## ✨ Основные функции

### 💬 Чаты
- Личные сообщения с ИИ-помощником (через Pollinations AI)
- Публичные и приватные каналы
- Комментарии к постам в каналах
- Реакции на сообщения
- Голосовые сообщения
- Отправка фото и стикеров
- Исчезающие сообщения
- Упоминания через @

### 📺 SkyView (Видеоплатформа)
- Загрузка и просмотр видео
- Создание каналов
- Лайки и избранное
- Режимы просмотра: сетка/список
- Фильтрация по категориям

### ️ SkyMail (Почта)
- Создание почтового аккаунта
- Папки: Входящие, Отправленные, Избранное, Черновики, Корзина
- Поиск по письмам
- Вложения файлов
- Звёздочки для важных писем

### 💪 SkyTraining (Фитнес)
- Запись тренировок
- Лента успехов
- Статистика (тренировки, калории, минуты, серии)
- Лайки на тренировки
- Готовые гайды по тренировкам

### 🗺️ SkyMaps (Карты)
- Интерактивная карта мира (Leaflet + OpenStreetMap)
- Поиск мест через Nominatim API
- Добавление маркеров
- Построение маршрутов через OSRM
- Слои: улицы, спутник, рельеф
- Геолокация

### 📞 Звонки
- Аудио и видеозвонки через WebRTC
- P2P соединение через localStorage
- Работает между вкладками одного браузера

### 🎨 Кастомизация
- 5 тем оформления (светлая, тёмная, зелёная, радужная, закат)
- Пользовательский цвет фона
- Загрузка фоновых изображений
- Анимированные облака

### 🏆 Геймификация
- Система уровней и опыта (XP)
- SkyCoins (внутренняя валюта)
- 20+ достижений
- Магазин тем, стикеров и эффектов

## 🛠️ Технологический стек

- **HTML5** — структура
- **CSS3** — стили с CSS-переменными и анимациями
- **JavaScript (ES6+)** — логика приложения
- **Leaflet.js** — карты

- **OSRM** — построение маршрутов

## 🚀 Установка и запуск

### Способ 1: Локальный запуск
1. Скачайте файл `index.html`
2. Откройте его в браузере (Chrome/Edge/Firefox)
3. Готово! 

### Способ 2: GitHub Pages (бесплатный хостинг)
1. Создайте репозиторий на GitHub
2. Загрузите `index.html` и переименуйте в `index.html`
3. Перейдите в **Settings → Pages**
4. Выберите ветку `main` и нажмите Save
5. Ваш мессенджер будет доступен по адресу: `https://ваш-ник.github.io/имя-репо/`

### Способ 3: Netlify (drag & drop)
1. Зайдите на [netlify.com](https://netlify.com)
2. Перетащите папку с `index.html` на сайт
3. Получите ссылку для доступа

## 🎯 Как использовать

1. **Регистрация**: Введите имя, логин и пароль
2. **Чаты**: Нажмите на "Поддержка" чтобы пообщаться с ИИ
3. **Видео**: Перейдите в SkyView и загрузите первое видео
4. **Почта**: Создайте аккаунт SkyMail и отправьте письмо
5. **Тренировки**: Добавьте первую тренировку в SkyTraining
6. **Карты**: Найдите место и проложите маршрут в SkyMaps
